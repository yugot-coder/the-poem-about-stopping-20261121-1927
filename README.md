# the-poem-about-stopping-20261121-1927 — Stopping Was Mine

A short poem about agency: the power to stop and to stay. A finger
hovers over Send — one more word and the machine would run all night.
The speaker lets the cursor blink, lets it wait, and chooses to stop.
Not from fear of going on, but because going on was easy, and stopping
was mine.
